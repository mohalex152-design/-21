# خمن أعلام — النسخة المطوّرة

## التشغيل
1. فك ضغط الملف كاملًا في مجلد.
2. افتح المجلد في VS Code.
3. شغّل `index.html` باستخدام Live Server.
4. يلزم الاتصال بالإنترنت لتحميل بعض بيانات الدول وصور الأعلام وخرائط OpenStreetMap.

## المميزات المضافة
- XP ومستويات محفوظة محليًا، مع مكافآت نهاية الجولة.
- ملف لاعب محلي: الاسم، الصورة الرمزية، واللقب.
- إنجازات محفوظة/محتسبة من التقدم المسجل.
- مود يومي ثابت حسب تاريخ اليوم، وتحدي ذاكرة منفصل، ومود مراجعة الأخطاء.
- سجل آخر 30 جولة وإحصائيات عامة.
- حفظ الدول التي أُجيب عنها خطأ لتدريب مخصص لاحقًا.
- مستكشف خريطة: اختر قارة ثم دولة لعرض موقعها على خريطة تفاعلية.
- تنزيل بطاقة النتيجة كصورة PNG.
- الحفاظ على المود الكلاسيكي والمودات المنفصلة والموسوعة والشعار الحالي.

## الخصوصية
التقدم والملف الشخصي والأخطاء والسجل محفوظة في `localStorage` على نفس المتصفح والجهاز. مسح بيانات الموقع قد يمسح هذا التقدم. لا يوجد حساب أونلاين أو مزامنة بين الأجهزة في هذه النسخة.

## ملاحظات الاختبار
تم التحقق من صياغة JavaScript باستخدام `node --check`، ومن وجود جميع معرّفات HTML التي يستخدمها JavaScript، وسلامة بنية ملفات المشروع. لم يتوفر اختبار بصري داخل متصفح آلي في بيئة البناء الحالية.

## نظام فتح المودات ومضاعفات XP
المود الكلاسيكي وتحدي اليوم متاحان من البداية. المودات الإضافية تُفتح حسب رصيد XP، ويُضرب رصيد خبرة الجولة الأساسي في المضاعف الموضح داخل بطاقة المود:
- طور السرعة: 100 XP لفتحه — ×2
- تحدي الذاكرة: 1,000 XP — ×4
- تحدي الخرائط: 2,000 XP — ×8
- مود الكومبو: 4,000 XP — ×13
- مراحل القارات: 6,000 XP — ×16
- معلومات بعد الإجابة: 8,000 XP — ×20
- لاعبان على جهاز واحد: 12,000 XP — ×25
- تحدي الخبرة: 15,000 XP — ×30

تُعرض المودات المقفولة مع تكلفة الفتح، وتتحقق اللعبة من رصيد XP مرة أخرى عند محاولة بدء المود، فلا يمكن تجاوز شرط الفتح بالنقر على البطاقة.


## اللعب أونلاين مع صديق باستخدام كود غرفة
أُضيفت واجهة لإنشاء غرفة خاصة من 6 أحرف/أرقام أو الانضمام إليها بالكود. المضيف ينتظر دخول لاعب ثانٍ، ثم يبدأ مباراة من 10 أسئلة، وتظهر الإجابات والنتيجة لكل لاعب مباشرة. هذه الميزة تحتاج ربطًا بمشروع Firebase خاص بك؛ لا يمكن تشغيل غرف حقيقية بين أجهزة مختلفة بملفات HTML محلية وحدها.

### إعداد الاتصال (مرة واحدة)
1. افتح [Firebase Console](https://console.firebase.google.com/) وأنشئ مشروعًا.
2. من إعدادات المشروع، أضف تطبيق Web وانسخ `apiKey` و`authDomain` و`databaseURL` و`projectId` و`appId` إلى ملف `firebase-config.js` بدل القيم التجريبية. رابط قاعدة البيانات يظهر في صفحة Realtime Database بعد إنشائها.
3. من **Authentication → Sign-in method** فعّل **Anonymous**.
4. من **Realtime Database** أنشئ قاعدة بيانات.
5. افتح تبويب **Rules** وانسخ قواعد `firebase-database.rules.json` ثم اضغط **Publish**. القواعد تشترط تسجيل دخول مجهول وتحدّ الكتابة على الغرف التي ينتمي إليها اللاعب، لكنها ليست بديلًا عن مراجعة قواعد أمان مخصصة إذا تحوّلت اللعبة لخدمة عامة كبيرة.
6. انشر ملفات الموقع على استضافة HTTPS مثل Firebase Hosting أو GitHub Pages. أضف نطاق الموقع إلى **Authentication → Settings → Authorized domains** عند الحاجة. يجب أن يفتح صديقك نفس رابط الموقع من جهازه؛ كود الغرفة وحده لا يستضيف اللعبة.
7. افتح «العب أونلاين مع صاحبك»، أنشئ غرفة، وانسخ الكود وابعته لصاحبك. صديقك يكتب الكود في نفس الصفحة.

### ملاحظات
- ملفات المشروع لا تحتوي على مفاتيح Firebase خاصة؛ ملف الإعداد يبدأ بقيم توضيحية ويجب إكماله من حسابك.
- اللعب الأونلاين هنا عبارة عن مباراة متزامنة للاعبين اثنين. يحتاج كلا الجهازين إلى الإنترنت، وخدمة Firebase مُهيأة، واستضافة الموقع على رابط يمكن للطرفين فتحه.
- التحقق من صياغة الملفات لا يغني عن اختبار اتصال فعلي بعد إدخال بيانات مشروع Firebase الخاص بك.


## السوق وفصل بيانات اللاعبين
- تمت إضافة سوق داخل صفحة الحساب: أعلام جميع أعضاء جامعة الدول العربية (بما فيها فلسطين) بسعر 50 عملة لكل علم، وأعلام دول عالمية وشخصيات تاريخية وإطارات وإضافات بالأسعار الظاهرة داخل السوق.
- التحويل: كل 100 XB = عملة سوق واحدة؛ لا يمكن التحويل إذا كان الرصيد غير كافٍ أو المبلغ ليس مضاعفًا لـ100. تكسب XB مع مكافآت XP، لكن XP نفسه لا يُخصم عند الشراء.
- التقدم والسجلات والملف الشخصي والمشتريات تُحفظ محليًا بمفتاح منفصل لكل اسم لاعب على نفس المتصفح. أول اسم يستخدم النسخة بعد التحديث يرث بيانات التقدم القديمة لمرة واحدة؛ الأسماء التالية تبدأ ببيانات مستقلة.
- هذا ليس تسجيل دخول آمنًا بكلمة مرور ولا مزامنة سحابية؛ أسماء اللاعبين المحلية ليست حسابات موثقة، وللمزامنة بين الأجهزة نحتاج إعداد Firebase Authentication وقاعدة بيانات وربط كل سجل بمعرّف المستخدم.
